# Temp Mail
Проект Temp Mail для Android, разработанный с помощью искусственного интеллекта.

Это приложение позволяет создавать временные почтовые адреса сроком на 1 час — вы можете создать совершенно новый адрес всего за 5 секунд!

На этой странице вы также можете посмотреть полный исходный код данного приложения, от вас ничего не скрвыают. вы можете делать свои форки или взаимодействовать с исходным кодом как вы сами пожелаете!
